How the Triangle Changes with Yaw

Right-angle corner always at (x + dx, y) — but dx can be negative

hypotenuse (front_min)
dx = front_min·cos(yaw)
dy = front_min·sin(yaw)
yaw = 45°
cos(45°) = +0.71 → cube RIGHT of robot
sin(45°) = +0.71 → cube ABOVE robot
yaw = 90°
cos(90°) = 0 → no horizontal shift
sin(90°) = +1 → cube directly above
yaw = 135°
cos(135°) = −0.71 → cube LEFT of robot
sin(135°) = +0.71 → cube ABOVE robot
dx is negative → corner flips left
yaw = 180°
cos(180°) = −1 → cube directly left
sin(180°) = 0 → no vertical shift

Triangle corner is always at (x + dx, y). When dx is negative the corner sits to the LEFT of the robot. The right angle is always between the two legs — it just moves sides.
